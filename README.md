# IIBA-ECBA Practice Studio®

Public static study tool for ECBA preparation. Open index.html to choose timed or untimed practice, select domains, and build a Study Session.

Quiz results are saved automatically in the learner’s browser on the same device. The Executive Assessment Report Card is generated from the latest saved result and can be printed or saved as a PDF. The public site does not collect or centrally store learner answers.

The simulator master prompt and supplied IIBA source PDFs are not included in this public site. This is an independent study resource, not an official IIBA product or endorsement. BABOK® is a registered trademark of the International Institute of Business Analysis.
