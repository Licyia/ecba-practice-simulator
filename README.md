# IIBA®-ECBA Practice Studio

Public static study tool for ECBA preparation. Open index.html to configure and start one learner-selected Study Session. The fixed question-set library is not published as a learner-facing feature.

Quiz results are saved automatically in the learner’s browser on the same device. The Executive Assessment Report Card is offered at the end of a session, already populated from the saved result, and can be shared or printed as a PDF. The public site does not collect or centrally store learner answers.

The simulator master prompt and supplied IIBA source PDFs are not included in this public site. This is an independent study resource, not an official IIBA product or endorsement. BABOK® is a registered trademark of the International Institute of Business Analysis.
